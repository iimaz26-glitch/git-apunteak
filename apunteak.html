Git eta GitHub-eko apunteak

1. Git

Zer da Git?

Git bertsio-kontrolerako programa bat da. Fitxategietan egindako aldaketak gordetzeko eta aurreko bertsioak berreskuratzeko erabiltzen da.

Git-eko oinarrizko komandoak

git init: Biltegi lokal berri bat sortzeko.

git add: Aldaketak hurrengo commit-erako prestatzeko.

git commit: Prestatutako aldaketak biltegi lokalean gordetzeko.

git status: Biltegiaren uneko egoera ikusteko.

git log --oneline: Commit-en historia modu laburrean ikusteko.

git checkout: Adar edo bertsio batetik bestera aldatzeko.

2. GitHub

Zer da GitHub?

GitHub Git biltegiak Interneten gordetzeko, partekatzeko eta taldean lan egiteko plataforma da.

Zer da urruneko biltegia?

Interneten gordetzen den Git biltegia da. Beste pertsonekin lan egiteko eta fitxategiak partekatzeko erabiltzen da.

GitHub-eko oinarrizko komandoak eta kontzeptuak

origin: Urruneko biltegiari ematen zaion izen ohikoena da.

git push: Lokaleko commitak urruneko biltegira igotzeko.

git pull: Urruneko biltegiko aldaketak lokalera ekartzeko eta bateratzeko.

git clone: Urruneko biltegiaren kopia osoa ordenagailura deskargatzeko.

Zer da Pull Request?

Adar bateko aldaketak beste adar batean sartzeko eskaera da. Aldaketak berrikusi eta onartzeko aukera ematen du.
